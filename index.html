大会主催者向け 運営ガイド

大会をつくって、
当日の記録まで

大会の作成、エントリーの承認、参加費の受け取り、対戦の組み立て、そして当日の試合記録まで。運営に必要な操作を、実際の画面にそって順番に案内します。

大会当日、記録を担当される方へ 試合結果の入力手順は第9章にまとめています→

大会参加者の方へ

  • チームを作って大会にエントリーする手順は、参加者向けガイドにまとめています。
  • 参加者は、大会作成側の設定によっては代表者だけでエントリーを完了できます（選手全員の登録は不要）。この設定は第2章で行います。

大会に参加する方は 参加者向けガイド →

準備する第01章

大会を開く（運営を始める）

大会づくりは、ヘッダーメニューの「大会管理」から始まります。ログイン中のアカウントが、そのまま大会の責任者になります。

入口ヘッダーメニュー →「大会管理」

  1. メニューから大会管理へ

    右上のメニューを開き、一番下のアカウント名を押します。展開された中の「大会管理」を選ぶと、管理している大会の一覧が開きます。新しく作るときは、そこから「＋大会を作成」に進みます。

第01章 ここまで

準備する第02章

大会をつくる

1つのフォームで、基本情報・エントリー条件・参加費・メンバー登録の要否まで設定します。作成すると、あなたが自動的に大会責任者になります。

入口大会管理 →「＋大会を作成」

  1. 基本情報を入力する

    大会名・種目・開始／終了日時・都道府県・会場詳細を入力します。複数日開催のときは、終了日時に最終日の時刻を入れます。

  2. 種目を選ぶ

    バスケットボール・フットサル・ハンドボール・水球・フィールドホッケーから選びます。

  3. 都道府県を選ぶ

    開催地の都道府県を選びます。

  4. 説明とエントリー条件を決める

    地図URL（任意）を入れると詳細ページに地図リンクが、大会紹介URL（任意）を入れると公式サイトへのリンクが表示されます。大会説明は1000文字まで。続けて、エントリー定員（参加できるチーム数の上限）と、エントリーステータス（受付中／受付終了）を設定します。

  5. 参加費と振込先口座を設定する

    「参加費徴収あり」にすると、参加費用・支払い方法・支払い期限を設定できます。この画面で選べるのは銀行振込と現金手渡しです。銀行振込を使う場合は、銀行名・銀行コード・支店名・支店コード・口座番号・口座名義がすべて必須になります。現金手渡しだけなら、口座の入力は不要です。

  6. ！

    クレジットカード決済をご希望の場合

    クレジットカードで参加費を集めるには、Halosports事務局が大会の運営者として加わる必要があります。ご希望の場合は、大会を作成する前に事務局（Welcome@halosports.jp）までご連絡ください。

  7. メンバー登録の要否を決める

    「メンバー登録必須」をオンにすると、出場選手の事前登録が必要になります。オフなら、代表者だけでエントリーを完了できます。任意で性別・生年月日の登録や、自由項目（最大8件）も足せます。なお大会を作成すると、あなたが自動的に大会責任者になります。責任者や運営者の追加は、作成後に大会詳細ページから行います（第7章）。

  8. ＋

    「メンバー登録必須」は、参加のしやすさと記録の細かさのトレードオフです

    オフにすると、参加者は代表者一人でエントリーを完了できます。選手一人ひとりのアカウントは不要なので、参加のハードルは下がります。ただし第9章の試合記録は背番号で入力するため、選手が登録されていないと「誰の得点か」を名前で残せません。個人成績を使いたい大会ではオンにしてください。

  9. 大会を作成する

    入力を確認し「大会を作成」を押します。確認ダイアログで「大会を作成」を選ぶと確定します。

  10. 作成完了

    大会詳細ページが開きます。大会IDが発行され、入力した内容が「大会情報」に反映されます。ここからの運営は、左上の「大会運営メニュー」から進めます。

第02章 ここまで

準備する第03章

運営メニューを知る

作成後の運営は、すべて「大会運営メニュー」に集まっています。押すと6つの項目が開きます。ここが運営の司令塔です。

入口大会詳細 →「大会運営メニュー」

  1. 運営メニューを開く

    大会詳細ページの「大会運営メニュー」を押すと、運営に必要な操作が一覧で開きます。

  2. ＋

    6つのメニューと、この本の対応

    「エントリー管理」＝参加チームの承認（第4章）、参加メンバー名簿の確認（第5章）、参加費の入金確認（第6章）。「スタッフ管理」＝運営を手伝う人の追加（第7章）。「試合を作成」「グループを作成」「トーナメント表を作成」＝対戦の組み立て（第8章）。作成した試合を開くと、当日の記録に進みます（第9章）。「大会情報を編集」＝作成した内容の修正。

第03章 ここまで

参加チームを集める第04章

エントリーを承認する

参加チームからのエントリーは「申請 → 主催者の承認」で確定します。承認するまで出場は確定しません。届いた申請を確認して、順に承認していきます。

入口大会運営メニュー →「エントリー管理」

  1. エントリー管理を開く

    画面上部に、申請中・変更申請・承認済み・却下の件数と、承認済みチームから集まる総参加費が表示されます。その下に、状態ごとの一覧が並びます。

  2. 申請内容を確認して承認する

    申請中のチームには、チーム名・所在地・チームメンバー数・参加費・支払い方法・申請日時が表示されます。「詳細」から中身を確認したうえで、「承認」または「却下」を押します。

  3. 承認後の状態を確認する

    承認すると、承認済みの件数と総参加費に反映されます。申請がすべて処理されると、申請中の欄は空になります。

  4. ＋

    承認は後から取り消せます

    承認済みのチームには「承認キャンセル」が表示されます。誤って承認した場合や、辞退の連絡があった場合はここから戻せます。

  5. ＋

    定員に達したら受付を閉じます

    エントリーステータスは、大会情報の編集から「受付終了」に切り替えられます（第2章）。

第04章 ここまで

参加チームを集める第05章

参加メンバー名簿を確認する

「メンバー登録必須」をオンにした大会では、各チームが出場選手を登録します。主催者は、その名簿を画面上でいつでも確認できます。名簿をメールで集めて集計する作業は必要ありません。

入口エントリー管理 → チームの「詳細」

  1. チームの参加メンバーを開く

    チームの詳細を開くと、大会エントリー時に登録されたメンバーが人数つきで表示されます。一人ずつ、本名・背番号・大会作成時に設定した自由項目が並びます。

  2. 名簿とチーム情報を確認する

    下にスクロールすると、残りのメンバーと、チーム名・所在地・チーム説明が続きます。

  3. ＋

    名簿をメールで集める作業がなくなります

    Excelを添付して各チームに配り、締切を追いかけて回収し、手元で1つにまとめる——という一連の作業が不要になります。締切に間に合っていないチームも、チームメンバー数を見ればその場で分かります。

  4. ！

    この画面は「メンバー登録必須」がオンの大会だけです

    第2章でオフにした大会では、選手個人の登録が行われないため、名簿は集まりません。

第05章 ここまで

参加チームを集める第06章

参加費の入金を確認する

「参加費徴収あり」で作成した大会では、チームごとの支払い状況をこの画面で管理します。誰が払っていて、誰がまだかが一覧で分かります。

入口大会運営メニュー →「エントリー管理」→ 下へスクロール

  1. 支払い状況を一覧で見る

    入金の管理は、第4章と同じエントリー管理のページで行います。下へスクロールすると「支払い状況」の絞り込みが現れ、すべて／未払い／支払い済みを切り替えられます。チームごとに、参加費・支払いステータス・支払い方法（現金／銀行振込など）が並びます。

  2. 入金を確認したら更新する

    銀行振込や現金手渡しで入金を確認したら、そのチームの「支払い済みに更新」を押します。ステータスが切り替わります。

  3. ＋

    「払いましたか」の後追い連絡が減ります

    「未払い」で絞り込めば、連絡すべきチームだけが残ります。全体宛のリマインドを何度も送る必要がなくなります。

第06章 ここまで

大会の直前に第07章

運営スタッフを追加する

大会運営を複数人で分担するときは、スタッフを追加します。当日の試合記録を誰かに任せる場合も、ここでの追加が必要です。

入口大会運営メニュー →「スタッフ管理」

  1. スタッフ管理を開く

    「スタッフを追加」の検索欄、「承認待ち」、現在の「責任者」の一覧が表示されます。

  2. ユーザーを検索して追加する

    ユーザー名またはユーザーIDを入力すると、候補が表示されます。選んで追加します。

  3. ！

    当日の朝では間に合いません

    追加したユーザー本人がマイページから承認して、初めてスタッフとして有効になります。本人の操作が挟まるため、当日の記録係は前日までに追加し、承認まで済ませておいてください。「承認待ち」が0件になっていれば完了です。

第07章 ここまで

大会の直前に第08章

対戦を組む

エントリーが固まったら、対戦を組みます。1試合ずつ作る「個別試合作成」、総当たり戦を一括生成する「グループ作成」、勝ち上がり式の「トーナメント表」の3つがあります。大会の形式に合わせて使い分けます。

入口大会運営メニュー →「試合を作成」「グループを作成」「トーナメント表を作成」

  1. 個別試合作成：1試合ずつ作る

    ホームチームとアウェイチーム、試合日時を指定します。1ピリオドの時間は試合ごとに設定でき、初期値は8分です。「予備情報」は任意で、審判名やコート番号などの補足を書いておけます。

  2. グループ作成：総当たり戦を一括で生成する

    グループ名と1ピリオドの時間、試合日時を決め、参加チームを2つ以上選びます。選んだチーム同士の総当たり戦が自動生成されます（4チームなら6試合）。日時は全試合に一括で入り、あとから試合ごとに変更できます。

  3. トーナメント表を作成する

    チームを1つずつ選ぶのではなく、参加チーム数をプルダウンで指定します。選ぶとラウンド数・総試合数・ラウンド別の試合数がプレビューされます（8チームなら3ラウンド7試合）。作成すると試合枠が自動生成されるので、各試合にチームを割り当てて進めます。試合結果を入力すると、勝者が自動的に次のラウンドへ進みます。

第08章 ここまで

大会当日第09章

試合結果を記録する

ここからが大会当日の操作です。得点やファウルを起きた順に登録していくと、スコアは自動で計算されます。この章は、当日初めて画面に触れる記録係の方が読むことを想定して、他の章より細かく載せています。

入口試合の詳細ページ →「イベント管理」

  1. ＋

    はじめに、この3つだけ覚えてください

    ①担当する試合を開いて「イベント管理」に入る ②起きたことを「チーム → 種別 → 背番号 → 残時間」の順に入れて登録する ③試合が終わったら結果を登録して確定する。この繰り返しです。入力を間違えても、あとから直せます。

  2. 担当する試合を開く

    試合の詳細ページには、対戦カード・日時・1ピリオドの時間と、現在のスコアが表示されます。記録を始めるには「イベント管理」を押します。

  3. イベント管理の画面を確認する

    上から順に、試合情報、現在のスコア、クォーターの切り替え、そして入力欄（イベント追加）が並びます。まず、これから記録するクォーターが合っているかを確認してください。

  4. 1. どちらのチームかを選ぶ

    入力欄はチーム選択から始まります。得点やファウルがあったチームを押します。選んだチームは色が変わり、画面上部にも表示されます。

  5. 2. イベントの種別を選ぶ

    「得点」「ファウル」「T.O（タイムアウト）」から選びます。選ぶと、こちらも色が変わります。

  6. 3. 背番号を入力する

    テンキーで選手の背番号を入力し、チェックボタンで確定します。入れ間違えたら「クリア」で消せます。

  7. 4. 残時間を入力する

    そのプレーが起きた時点の残り時間を、分と秒それぞれのテンキーで入力し、「確定」を押します。ここまで入力が終わるまで「イベントを追加」は押せません。

  8. イベントを追加する

    4つすべてが入力されると「イベントを追加」が押せるようになります。押すと登録されます。入力をやり直したいときは「リセット」で全部消せます。

  9. 登録された内容を確認する

    登録したイベントは「試合イベント」の一覧に並び、スコアに自動で反映されます。クォーター・種別・時間・得点・チーム・背番号が表示されます。

  10. 試合が終わったら結果を登録する

    「試合結果登録」まで下がります。現在のスコアはイベントから自動計算されているので、通常は「自動判定」のまま「試合結果を登録する」を押します。これで試合が確定します。

  11. ＋

    背番号と選手名のつながりについて

    イベントは背番号で登録します。その背番号のメンバーがチームから登録されていれば、一覧には登録者の名前が並んで表示されます（第5章）。メンバー登録のない大会では、代表者のアカウント名が表示されます。

  12. ＋

    登録した結果は積み上がります

    確定した試合結果はレーティングに反映され、大会をまたいで蓄積されます（第10章）。

第09章 ここまで

大会のあとで第10章

記録が積み上がるということ

登録した試合結果は、その大会で終わりません。勝敗はレーティングポイントとして計算され、競技全体のランキングに反映されます。大会を重ねるほど、チームの実力が数字として残っていきます。

入口ヘッダーメニュー →「ランキング」

  1. チームランキングを見る

    種目ごとに、レーティングポイントの高い順にチームが並びます。ポイントと、通算の勝敗数が表示されます。

  2. ＋

    1大会で完結しない記録

    第9章で試合結果を登録すると、レーティングが再計算されます。この計算は大会をまたいで続くため、同じチームが別の大会に出るたびにポイントが更新されます。主催者にとっては、自分の大会の結果が参加チームの記録として残り続ける、ということでもあります。

  3. ！

    これは大会ごとの順位表ではありません

    ここに表示されるのは、その競技に参加しているチーム全体のランキングです。自分の大会に出たチームだけを見たい場合は、大会ページの試合結果を確認してください。

  4. ！

    来年の大会について

    過去の大会をコピーして新しい大会を作る機能は、現在のところありません。次の大会は、第1章から新しく作成してください。
