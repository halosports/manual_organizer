第01章

大会をひらく（運営をはじめる）

大会作成の入口は2つ。ヘッダーメニューの「大会管理」か、大会管理トップの「＋大会を作成」から始めます。

入口ヘッダーメニュー →「大会管理」

  1. メニューから大会管理へ

    ヘッダーメニューをひらき、アカウント名の下にある「大会管理」を選びます。ログイン中のアカウントで操作します。

  2. 大会管理トップをひらく

    管理している大会の一覧が表示されます。新しく作るときは「＋大会を作成」を押します。

第02章

大会をつくる

1つのフォームで、基本情報・エントリー条件・参加費・メンバー登録の要否まで設定します。作成すると、あなたが自動的に大会責任者になります。

入口大会管理 →「＋大会を作成」

  1. 基本情報を入力する

    大会名・種目・開始／終了日時・都道府県・会場詳細を入力します。複数日開催のときは、終了日時に最終日の時刻を入れます。

  2. 種目を選ぶ

    バスケットボール・フットサル・ハンドボール・水球・フィールドホッケーから選びます。

  3. 都道府県を選ぶ

    開催地の都道府県を選びます。

  4. 地図・紹介URL・説明を足す

    地図URL（任意）を入れると詳細ページに地図リンクが、大会紹介URL（任意）を入れると公式サイトへのリンクが表示されます。大会説明は1000文字まで。

  5. エントリー条件を決める

    エントリー定員（参加できるチーム数の上限）と、エントリーステータス（受付中／受付終了）を設定します。

  6. 参加費を設定する

    「参加費徴収あり」にすると、参加費用・支払い方法（クレジットカード／銀行振込／現金手渡し）・支払い期限を設定できます。振込を使う場合は振込先口座も入力します（現金手渡しのみなら口座入力は不要）。

  7. メンバー登録の要否を決める

    「メンバー登録必須」をオンにすると、出場選手の事前登録が必要になります。オフなら、代表者だけでエントリーを完了できます。任意で性別・生年月日の登録や、自由項目（最大8件）も足せます。

  8. ＋

    「メンバー登録必須」は参加ハードルに直結します

    オフにすると、参加者は代表者ひとりでエントリーを完了できます。選手一人ひとりのアカウントは不要です。まずは参加してもらいたい大会では、オフから始めるのがおすすめです。個人成績や得点ランキングを使いたくなったら、オンに切り替えます。

  9. 大会を作成する

    入力を確認し「大会を作成」を押します。確認ダイアログで「大会を作成」を選ぶと確定します。

  10. 作成完了

    大会詳細ページ（運営者向け）が開きます。左上の「大会運営メニュー」から、ここまでの続きを進めます。

第03章

運営メニューを知る

作成後の運営は、すべて「大会運営メニュー」に集まっています。ここが運営の司令塔です。

入口大会詳細 →「大会運営メニュー」

  1. 運営メニューをひらく

    大会詳細ページの「大会運営メニュー」を押すと、運営に必要な操作が一覧で開きます。

  2. ＋

    各メニューでできること

    「大会情報を編集」＝作成した内容の修正。「スタッフ管理」＝運営を手伝う人の追加（第7章）。「エントリー管理」＝参加チームの申請確認・承認（第4章）と、登録された参加メンバー名簿の確認（第5章）。「口座管理」＝参加費の入金確認（第6章）。「試合を作成」「グループを作成」「トーナメント表を作成」＝対戦の組み立て。

  3. ！

    対戦の組み立てについて

    試合作成・グループ・トーナメント表の詳しい手順は、次版で画面つきで追加します。

第04章

エントリーを承認する

参加チームからのエントリーは「申請 → 主催者の承認」で確定します。承認するまで出場は確定しません。届いた申請を確認して、順に承認していきます。

入口大会運営メニュー →「エントリー管理」

  1. エントリー管理をひらく

    大会運営メニューから「エントリー管理」を選びます。申請中・承認済みのチームが一覧で並びます。

  2. 申請中のエントリーを確認する

    申請中のチームには、チーム名・代表者・申請日時が表示されます。カードを開くと、登録された内容を確認できます。

  3. 承認する

    「承認」を押すと確認ダイアログが表示されます。内容を確認して承認すると、そのチームの出場が確定します。

  4. 承認後の状態を確認する

    承認したチームは一覧上で状態が変わり、エントリー数に反映されます。定員に達したら、大会情報の編集からエントリーステータスを「受付終了」に切り替えます。

  5. ＋

    参加条件を満たさない申請は却下できます

    却下すると、そのチームは出場チームに含まれません。判断に迷う場合は、承認せずに保留したまま代表者に連絡を取ることもできます。

第05章

参加メンバー名簿を確認する

「メンバー登録必須」をオンにした大会では、各チームが出場選手を登録します。主催者は、その名簿を画面上でいつでも確認できます。名簿をメールで集めて集計する作業は必要ありません。

入口エントリー管理 → チームを選ぶ

  1. チームの参加メンバーを開く

    エントリー管理の一覧からチームを選ぶと、そのチームが登録した参加メンバーが表示されます。

  2. 名簿の中身を確認する

    登録された選手の情報（大会作成時に指定した項目）を一覧で確認できます。未登録のチームも一目で分かります。

  3. ＋

    名簿をメールで集める作業がなくなります

    Excelを添付して各チームに配り、締切を追いかけて回収し、手元で1つにまとめる——という一連の作業が不要になります。締切に間に合っていないチームも、画面を見ればその場で分かります。

  4. ！

    この画面は「メンバー登録必須」がオンの大会だけです

    第2章で「メンバー登録必須」をオフにした大会では、選手個人の登録が行われないため、名簿は集まりません。名簿を管理したい大会では、作成時にオンにしておきます。

第06章

参加費の入金を確認する

「参加費徴収あり」で作成した大会では、チームごとの支払い状況をこの画面で管理します。誰が払っていて、誰がまだかが一覧で分かります。

入口大会運営メニュー →「口座管理」

  1. 口座管理をひらく

    大会運営メニューから「口座管理」を選びます。参加費の設定内容と、チームごとの支払い状況が表示されます。

  2. 支払いステータスを確認する

    チームごとに支払い状況が表示されます。未入金のチームだけを拾って連絡できます。

  3. 入金を確認する

    銀行振込・現金手渡しの場合は、入金を確認したうえで主催者側でステータスを更新します。

  4. 現在残高を確認する

    集まっている参加費の合計を確認できます。

  5. ＋

    「払いましたか」の後追い連絡が減ります

    支払い期限を過ぎているチームがその場で特定できるため、全体宛のリマインドではなく、必要なチームにだけ連絡できます。

第07章

運営スタッフを追加する

大会運営を複数人で分担するときは、スタッフを追加します。追加された人も、自分のアカウントから運営メニューを開けるようになります。

入口大会運営メニュー →「スタッフ管理」

  1. スタッフ管理をひらく

    大会運営メニューから「スタッフ管理」を選びます。現在の運営メンバーが一覧で表示されます。

  2. スタッフを追加する

    運営を手伝ってもらう人を追加します。追加された人は、自分のアカウントからこの大会の運営メニューを開けるようになります。

  3. ！

    この先は次版で追加します

    試合の作成、グループ・トーナメント表の組み立て、当日のスコア入力については、次版で画面つきで追加します。
